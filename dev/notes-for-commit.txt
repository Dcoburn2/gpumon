Use the installer switch PawnIO actually documents

PawnIO_setup.exe was run with /S. That is the NSIS convention and a reasonable
guess, and it is wrong: the installer answers with a message box - "Unknown
argument: /S" - followed by its usage,

    PawnIOSetup.exe [-install] [-uninstall] [-unrestricted] [-debuginfo] [-silent]

so the driver was never installed and the sensor setup had nothing to read. That is
what somebody saw on their AMD machine: the dialog, and then no CPU temperature.

It now runs -install -silent, which is the pair that works. -unrestricted is
deliberately not used: that is the edition which loads unsigned modules, a security
downgrade for no gain, since the modules gpumon loads are PawnIO's signed ones.

The test checks the switches against the usage text rather than trusting the code:
that -install and -silent are both there, that neither /S nor /s is, that
-unrestricted is not, and that the uninstall pair matches the same usage. A guess
that produces a dialog box on somebody else's machine is worth a test.

If the installer still fails, it now says so and names the path, instead of
reporting a bare failure after twenty half-second waits.
